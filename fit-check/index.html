How is the house built?

How much attic insulation is there?

Eyeball it over the ceiling joists. This is what tells us whether a bigger unit is the answer, or whether topping the attic up gets the house there on the Manual J size.

2×6 joists are 5½" — insulation flush with the top of a 2×6 is about R-14 blown fiberglass. Las Vegas minimum R-38; today's code (2021 IECC, Clark County) is R-49 on new construction.

ACCA Manual D Friction Rate Worksheet: the blower table at the design static gives the airflow; the filter, coil, register, grille and damper drops come off it; what is left, spread over the longest supply and return paths (these lengths plus the equivalent length of every fitting — grille box, elbows, the roof-line metal, take-off collar, branch bend, boot), is the friction rate every duct is sized to. Thresholds

Manual D design point (in. w.c.)

Manual D runs forwards: the blower table at the design static gives the airflow, the filter / coil / register / grille / damper drops come off it, what is left over the total effective length is the friction rate, and every duct is the smallest standard size that holds it inside the velocity limits. The CFM quoted to the customer is the same table read at the limit above.

Airflow caps (max CFM through a spot)

Defaults are the Goettl method: grille 2.0 CFM/sq in (20×20 → 2 ton, 20×25 → 2.5 ton, 20×50 → 5 ton), round return at 900 fpm (14"→2T, 16"→3T, 18"→4T, 20"→5T), supply trunk and jack/transition openings 900 fpm. ACCA-conservative would be grille 1.5, return duct 700.

Red is always "new is bigger than the space (or the opening)". When no measurements are entered, options are judged against the old equipment: Lots of room → orange only if it grows more than 8". Some room → orange if it grows up to the tight threshold, red beyond that. Package units: Stand is green when the unit sits on the deck, orange when it overhangs by up to the overhang limit (deck extension / rail support), red beyond; Metal uses the opening-alignment thresholds for both position and opening size. Static pressure is acceptable up to the ductwork threshold (0.5–0.7" is higher but within limits); over it the tool recommends ductwork remediation.
