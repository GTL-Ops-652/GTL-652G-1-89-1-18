Paste the Master Pay File  (real installer pay — replaces the install assumption)

In Excel, select the whole Master Pay File sheet including column A (the Job Number: grouping rows), copy, and paste below. The tool reads each pay line, sums by job number across member jobs, and splits it into Install Pay (COMUT flat/task), Commissions (COM), Direct Adjustments, and Misc (BON / Smart Sadie / $30 / training). Real installer pay then drives margin instead of the assumed install %. Jobs with no install pay line use $0 install and show a ⚠ — those are the not-yet-paid exceptions to watch. Selling commission stays assumed (it lags). Paste the job costing report first, then this.

Paste the Invoice Item Detail  (real discounts — replaces the Price Variation assumption)

In Excel, select the whole Invoice Item Detail report including the header row, copy, and paste below. The tool reads every line, sums the negative-priced items per job, and computes Discount % = discount $ ÷ book price where book = sold + discount $. Excluded from the discount (tracked separately in the Excl. Credits column — hover any row for the itemized detail): RepairCredit, NV.ReplacementRebate, Retail-Special-$2500, and any Smart Sadie line. Paste the job costing report first, then this.

How this planner works

Scope. HVAC business units only. Job costing only. Projects roll to one margin each; standalone jobs pass through.

Job / Project column. Projects show the project number with a ▸ caret — click to expand the member job numbers inline, or hover the project number to see them in a tooltip. Standalone jobs show the job number directly.

Categories. Each job type maps to a Category from the mapping sheet (AC Install, Install AC Units, Install Duct, Install Parts, Maintenance, Service, Warranty, Callback, Retail, Non-Revenue, etc.). Filter by Category in the dropdown.

Pay plan (drives margin labor) — applies to every revenue job:

• Selling commission (assumed): Tech (9% max) + SM (3% max), stepping down by discount per the tiers. Assumed on every revenue job because commissions lag posting.

• Install pay (real): the actual installer/task pay from the Master Pay File, summed across member jobs. No longer assumed. A revenue install job with no install pay line yet shows ⚠ and counts $0 until it posts.

• $30 fee: adds on top for Maintenance & Warranty jobs only.

Assumed vs actual: margin uses whichever is higher — assumed plan (assumed comm + real install + $30) or combined actual labor (hourly + real comm + install + misc). When actual wins, the row shows an act badge.

Margin. GP = Revenue − Net Purchases − Margin Labor (higher of assumed/actual) − Burden − CC/Finance.

Labor bands. From your mapping sheet, per job type: a $ floor (low, reference only) and a % cap or $ cap (high). Actual labor above the cap → red (labor overrun). Under-floor flagging is off. Job types with no cap set don't flag. All editable in Variables.

Revenue note. The ServiceTitan report excludes adjustment invoices, so a job's revenue here can read lower than its ST total.
